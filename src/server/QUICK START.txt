CHAT BUBBLE - QUICK START
=========================

FIRST-TIME SETUP
----------------

1. Extract the entire ChatBubble.zip file.
   Do not run Chat Bubble from inside the ZIP.

2. Open the extracted ChatBubble folder.

3. Double-click:
   START CHAT.bat

4. If Windows asks, allow Node.js to install.
   After installation finishes, open START CHAT.bat again.

5. The first launch asks for your YouTube Data API key.
   Paste it and press Enter. It is saved only on this computer.

6. Paste your YouTube livestream Share link and press Enter.

7. Keep the Chat Bubble window open while streaming.


ADD CHAT BUBBLE TO OBS
----------------------

1. In OBS, open your scene.

2. In Sources, click + and select Browser.

3. Name the source:
   Chat Bubble

4. Enter these settings:

   URL:    http://127.0.0.1:3000/chat_box
   Width:  1400
   Height: 3000

5. Click OK.

6. Resize and position Chat Bubble in your OBS scene.

IMPORTANT:
Keep the Browser Source Width and Height at 1400 x 3000.
To make Chat Bubble look smaller or larger, scale the source in the
OBS preview instead of changing those browser dimensions.


EVERY STREAM AFTER SETUP
------------------------

1. Double-click START CHAT.bat.
2. Paste the current livestream Share link.
3. Press Enter.

Your API key and OBS Browser Source stay saved.


WHERE TO GET THE LIVESTREAM LINK
--------------------------------

Use the Share link from your YouTube livestream:

https://www.youtube.com/watch?v=VIDEO_ID

Short links also work:

https://youtu.be/VIDEO_ID

You may also paste the 11-character video ID by itself.


UPDATE CHAT BUBBLE
------------------

1. Download the newest ChatBubble.zip release.
2. Stop the old Chat Bubble window.
3. Extract the new ZIP into a new folder.
4. Run START CHAT.bat from the new folder.

Your YouTube API key is stored in your Windows user profile, so you
normally do not need to enter it again.


STOP CHAT BUBBLE
----------------

Close the Chat Bubble window.


SECURITY
--------

- Download releases only from the official GitHub Releases page.
- Compare ChatBubble.zip with the published SHA-256 file when needed.
- Check the release's VirusTotal safety report before running it.
- Never share your YouTube API key or commit it to Git.
