CHAT BUBBLE - QUICK START
=========================

You are installing Chat Bubble as a StreamElements Custom Widget.

You do NOT need to run a local server.
You do NOT need a YouTube API key.
You do NOT need to change OBS every stream after setup.


1. CONNECT YOUTUBE TO STREAM ELEMENTS
-------------------------------------

1. Open StreamElements.

2. Log in with the YouTube channel you stream from.

3. Allow the YouTube permissions StreamElements asks for.
   Use full permission for the channel connection so StreamElements can read
   live chat events.

4. For the first test, use a public YouTube livestream.

SE.Live note:
SE.Live is optional. It only makes StreamElements easier to use inside OBS.
The Chat Bubble widget still goes into the StreamElements overlay editor.


2. CREATE THE OVERLAY
---------------------

1. In StreamElements, open Overlays.

2. Create a new overlay/layout.

3. Set the layout size to:

   Width:  1400
   Height: 3000

4. Add:

   Static/Custom -> Custom Widget

5. close the setting -> open "Position, size and style" 

6. set Width 1400 Height 3000 -> then press the "Center widget" button

7. Only then reopen the Custom Widget settings.

8. Click:

   Open Editor


3. COPY AND PASTE THE WIDGET
----------------------------

In the StreamElements editor, paste each file into the matching tab:

   HTML tab    <- widget.html
   CSS tab     <- widget.css
   JS tab      <- widget.js
   Fields tab  <- widgetfield.json

Then click Done/Save.

Do not paste widgetdata.json into StreamElements.
It is only a local test/reference file.


4. COPY THE OVERLAY LINK
------------------------

1. Go back to the StreamElements overlay page.

2. Copy the overlay URL.

This is the URL you put into OBS.


5. ADD IT TO OBS
----------------

1. Open OBS.

2. Open your scene.

3. In Sources, click +.

4. Choose:

   Browser

5. Paste the StreamElements overlay URL.

6. Set:

   Width:  1400
   Height: 3000

7. Click OK.

8. Resize the source in the OBS preview if you want it smaller or larger.

IMPORTANT:
Keep the Browser Source width and height at 1400 x 3000.
Resize by scaling the source in OBS, not by changing those numbers.


6. FIRST REAL TEST
------------------

1. Start or schedule a public YouTube livestream.

2. Send a chat message from another account or phone.

3. Confirm the bubble appears in OBS.

If nothing appears, check in this order:

   1. YouTube account is connected to StreamElements.
   2. The stream is public.
   3. The Custom Widget was saved.
   4. OBS is using the StreamElements overlay URL.
   5. OBS Browser Source is 1400 x 3000.


7. UPDATING CHAT BUBBLE
-----------------------

1. Download the newest ChatBubble.zip.

2. Open your StreamElements Custom Widget editor.

3. Replace the old tabs with the new files:

   widget.html
   widget.css
   widget.js
   widgetfield.json

4. Save the widget.

Your OBS Browser Source can keep the same overlay URL.


8. SAFETY
---------

- Download ChatBubble.zip only from the official GitHub Releases page.
- Check the release safety/VirusTotal report if Windows or OBS warns you.
- Never paste private account passwords, tokens, or secrets into the widget.
