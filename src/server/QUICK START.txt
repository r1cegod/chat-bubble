CHAT BUBBLE - QUICK START
=========================

FIRST TIME

1. Extract the entire ChatBubble.zip file.
2. Open the extracted ChatBubble folder.
3. Double-click START CHAT.bat.
4. Allow the Windows installation prompt if one appears.
5. Paste your YouTube Data API v3 key.
6. Paste the YouTube livestream link. See the easy guide below.

The overlay opens automatically in your browser.

HOW TO GET THE LIVESTREAM LINK

EASIEST METHOD

1. Open the livestream's normal YouTube page.
2. Click Share under the video.
3. Click Copy.
4. Return to the black Chat Bubble window.
5. Right-click to paste, then press Enter.

Paste the whole link. You do not need to find or edit the video ID.

WORKING EXAMPLES

https://www.youtube.com/watch?v=AbCdEf12345
https://www.youtube.com/live/AbCdEf12345
https://youtu.be/AbCdEf12345

In all three examples, the video ID is:

AbCdEf12345

FALLBACK METHOD

If Share is unavailable, copy the full address from the browser's address bar.
Make sure it is the actual video page, not:

- YouTube Studio
- Your channel page
- The YouTube home page

OBS URL

http://127.0.0.1:3000/chat_box

The starter copies this URL to your clipboard automatically.
Add it to OBS as a Browser Source.

EVERY STREAM AFTER THAT

1. Double-click START CHAT.bat.
2. Open the livestream, click Share, click Copy, and paste the link.
3. Keep the black Chat Bubble window open.

UPDATE

1. Close Chat Bubble.
2. Double-click UPDATE CHAT.bat.
3. Wait for "Update complete."

Your saved API key is preserved.

You do not need to open or edit the "ChatBubble Files" folder.

WHAT THE APP DOES

- The API key is saved locally in "ChatBubble Files\.env".
- The API key is sent only to Google's YouTube API.
- Chat Bubble connects to YouTube/Google for live chat.
- Updates are downloaded from the public GitHub release page.
- First-time setup may install the official Node.js LTS package through winget.
- The overlay runs only on this computer at 127.0.0.1.
- Chat Bubble has no analytics, account system, or remote database.

For safer key handling, restrict the key to "YouTube Data API v3" in Google
Cloud Console. Do not send the key to anyone or show the .env file on stream.

Windows may show a permission prompt while Node.js is installed. The BAT files
run the included PowerShell setup scripts with a process-only execution-policy
override. They do not change the computer's permanent PowerShell policy.

STOP

Press Ctrl+C in the Chat Bubble window, or close the window.
